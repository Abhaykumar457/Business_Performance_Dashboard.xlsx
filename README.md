# Business Performance Dashboard – Excel

## Project Overview

This project is an Excel-based Business Performance Dashboard created to analyze business performance and present key insights through visualizations and KPIs.

## Key Analysis

- Revenue analysis
- Profit analysis
- Orders and units sold analysis
- Monthly performance analysis
- City-wise performance analysis
- Product-wise performance analysis
- Profit margin analysis

## Tools Used

- Microsoft Excel
- Excel Charts
- Excel Dashboard
- Data Visualization
